# Контроль переписок NikiRent

Одна страница: чат, дата и критерии проверки. Входа, базы и сервера нет. Живой MAX пока не подключён: открываются демо-чаты, свою выгрузку можно загрузить файлом.

«Принял», «ок» и «в работе» — подтверждение, не отчёт. Отчёт — сообщение с результатом: готово, отправила, фото, сумма, список.

## Как открыть

Нужны Node.js и npm.

```bash
npm install
npm run dev
```

Адрес: http://localhost:3000

Страница сразу читает `public/data/chats.json`. Кнопка «Загрузить файл» принимает json, csv или xlsx и меняет экран только в этой вкладке. Файл в проекте при загрузке не перезаписывается.

Проверка правил:

```bash
npm run check-data
```

## Как проверить

В поле «Поручение» можно написать своими словами, например: чат «Отдел заботы» за 22 ноября, поручения без отчёта, вопросы без ответа и сообщения, на которые вы не ответили. Кнопка «Проверить» выставляет чат, дату и галочки.

Чат, дату и галочки можно сменить и без текста. Вторая дата сравнивается с первой на графике. Клик по строке открывает сообщение, ответы после него и ссылку.

В таблице колонки: сотрудник, суть, короткое сообщение, ссылка.

## Файл выгрузки

Лист «Сообщения» или первый лист. Колонки: чат, дата, время, автор, роль, текст, ссылка. Роль — «руководитель» или «сотрудник». Ссылка — адрес конкретного сообщения в MAX. Id необязателен.

Json: список `chats`, у каждого `name` и `messages` с теми же полями. Роль в json: `manager` или `staff`.

## Ограничения

Разбор поручения и переписки сейчас идёт правилами, не языковой моделью. Так цифры можно проверить командой `check-data`. Модель и живой доступ к MAX — следующий шаг, когда доступ дадут без пароля.

Отчёт закрывает самое раннее ещё открытое поручение этого сотрудника до вашего следующего сообщения. Вопрос сотрудника не закрывается новым поручением другому человеку. Если в ответе нет имени, закрывается только последний открытый вопрос, и только если сообщение похоже на ответ, а не на новую задачу.

Ссылки в демо ведут на шаблон `max.ru` и не открывают рабочий чат. В своей выгрузке в колонке «ссылка» будет настоящий адрес.
